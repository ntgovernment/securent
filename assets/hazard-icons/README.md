# National Hazard Icons

Individual transparent WEBP exports of the six hazard pictograms shown on page 2 of the [National hazard icons - design guidelines](https://knowledge.aidr.org.au/media/8310/national-hazard-icons-design-guidelines.pdf) (Australian Institute for Disaster Resilience, last updated October 2020).

The set contains Fire, Storm, Flood, Cyclone, Heat, and Other, each in the Advice, Watch/Act, and Emergency Warning escalation tiers. Filenames use `<hazard>-<tier>.webp`, with tier suffixes `advice`, `watch_act`, and `emergency_warning`.

The PDF defines the tier colours as yellow `#FBE032` for Advice, orange `#FF7900` for Watch/Act, and red `#D6001C` for Emergency Warning, with black triangle outlines. The icons were rasterized from the PDF's vector artwork at 6 pixels per PDF point, with 5 points of transparent padding, then encoded as lossless WebP. The resulting images are approximately 582 × 550 pixels; a one-pixel width difference can occur from raster rounding.

The two-page source PDF contains no separate reuse or attribution statement. Source attribution: Australian Institute for Disaster Resilience, *National hazard icons - design guidelines*, page 2, October 2020. Reuse is subject to the permission confirmed for this repository by its owner.
